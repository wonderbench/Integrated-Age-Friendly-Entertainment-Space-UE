# 项目审计报告

日期：2026-09-03；工程：Old_Man_Jiang / UE5.8。目标是建立可供新线程接续的真实项目知识库，**不是本轮修复全部历史需求**。

## 结论

现有 C++ 行为层 + 原 Blueprint 配置/表现层的分工可继续使用，不需要重写。玩家观察与老人身份分离、统一状态入口、导航组件、事件式监控、复用原动画/UI/天气接口都是应保留的基础。

主要差距不是缺少更多蓝图名称，而是部分业务链没有闭合：监控实际使用球形范围；姿势动画只有槽位/钩子未接完整；警报由关卡开始启动而非跌倒触发；图表尚无已确认的真实业务统计来源；项目自有存档体系未找到。

**原 BPI_Actor_Call.Light_Show 仍在使用，不能整套删除用户灯光逻辑。** 天气/时间选择经 BGS_State 分发到带 BP_Light 标签的灯；单灯现有 Timeline 仍承担渐变。
