# ADR-004：根转身以实际播放器进度为准

状态：记录现有修复契约及历史回归理由，2026-09-03。

## Context

曾用外部时钟Evaluator从末尾跳回开头，实测瞬转/多转；只看最终朝向的测试漏掉这些问题。动画完成回调也曾受是否渲染影响。

## Decision / Reason

复用非循环TurnInPlace BlendSpacePlayer，分支激活重置；UE根运动驱动胶囊，Proxy.PostUpdate回报实际播放时间；新片段等待上一分支更新为inactive且旧混合权重归零。轻按松键不取消已开始转身，但不继续行走。

## Consequences

保留实际根Yaw倍率校准、转速锁定、短暂斜向输入合并；不能恢复结束强设朝向、手动重复累加根运动或外部相位跳变。轮椅程序转向与普通根转身区分。尚非联网方案。

## Do Not Change Unless

同时验证轻按/持键、连续和相邻方向、逐帧跳变、转身位移、结束姿态、有/无渲染完成、接管退出及原AI导航；不能只用终点角度判断成功。
