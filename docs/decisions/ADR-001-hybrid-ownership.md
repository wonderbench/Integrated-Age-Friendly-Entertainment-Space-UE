# ADR-001：保留原 Blueprint 与原生行为层

状态：记录已存在架构及本轮继续保留的约束，2026-09-03；不是本轮迁移。

## Context

老人、观察控制器、监控与15个UI已有 C++ 父类，原资源、布局和事件图持续迭代；天气灯光仍以原 Blueprint 为主。

## Decision / Reason

行为入口在现有原生类扩展，表现/配置保留原蓝图。玩家观察与老人分离，默认BP_Player，显式接管才控制BP_AI。避免重复系统及大范围资产重设父类。

## Consequences

审计和修改必须同时查 C++ 与 Blueprint；不能因 BP 图少就判定功能缺失。UI 统一父类不代表所有UI逻辑已经转成C++。

## Do Not Change Unless

有明确功能/加载/性能需求，检查全部引用与脏资产、精确备份，并提供迁移验收计划；不能为命名或“全C++更适合AI”自动迁移。
